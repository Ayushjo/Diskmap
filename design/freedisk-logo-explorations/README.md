# freedisk.space logo directions

The fourth direction, **Cleared stack**, is now the active freedisk.space logo in `../website-motion-v1/` and in the application. The earlier open-f version is preserved in `../website-motion-v11-backup/` and `../brand-backup-open-f/`.

- **Open disk:** closest to the product concept and most distinctive at large sizes; the ring can be too generic at favicon size.
- **Mapped f:** preserves an integrated first letter while connecting it to the storage map; strongest candidate to refine next.
- **Free corner:** recognizable storage blocks with an intentional opening; better as an app icon than a wordmark letter.
- **Cleared stack:** the selected identity. Its shrinking bars make the result of freeing space visible at icon size.

Each SVG is editable vector artwork. The selected mark is reproduced in the production SVGs and SwiftUI icon renderer.
