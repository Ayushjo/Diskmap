# DiskMap website visual study

Open `index.html` in a browser to review the direction. It is a static design study, not a published website or a production download page.

## Assets

- `diskmap-mark.svg` — the D mark, for small brand placements and the app icon source.
- `diskmap-wordmark.svg` — horizontal logo for navigation and footer.
- `hero-storage-map.svg` — wide illustration for the opening section.
- `hero-storage-map-mobile.svg` — re-composed map and inspector for narrow screens.
- `review-flow.svg` — scan, inspect, review story for wide screens; the preview uses HTML cards on narrow screens.
- `snapshot-change.svg` — an earlier-versus-now illustration for Snapshots.

The diagrams contain invented example data. They should be paired with real, matched-state screenshots when the marketing site is implemented. The page avoids unverified scan-time claims, pricing, and download links.

## Design direction

Use the selected segmented D as a small, repeated anchor. Put the storage map at the center of the site, supported by generous typography and calm editorial spacing. Let each section answer a concrete question: where is the space, what changed, and what happens before removal. Keep the product's review-first language and local-only promise visible in the copy. Motion, if added later, should clarify selection or comparison and respect reduced-motion preferences.

Suggested production sequence: redraw the final approved wordmark as carefully measured vector paths; capture real app screens at one scan state; implement the responsive website; then add restrained interaction to the map and snapshot comparison. This folder is standalone and does not change the Swift app.
